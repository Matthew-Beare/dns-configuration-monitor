# Public release boundary

This release was rebuilt from an original networking-course lab. Only the revised public implementation and selected, hand-reviewed screenshot crops are included. The original branches, network inventory, API bearer tokens, user/password columns, DNS server backups, course-specific settings, external URLs and full-desktop screenshots have deliberately not been copied into this repository.

Screenshots document original isolated lab sessions, not the new replay code. Their original PNG metadata was discarded, desktop/browser content was cropped away and lab IP values in the published crops were masked. **No screenshot output was fabricated.**

The example addresses use RFC 5737 documentation ranges and are not live hosts. The current code performs offline simulations by default. Optional SSH actions (where present) are gated behind explicit confirmation and require existing verified SSH host keys; only mocked tests have been performed on that functionality.

Tests cover simulated decisions, not actual access to WGU systems or production networks. The original course and operator credentials must never be published or reused.
